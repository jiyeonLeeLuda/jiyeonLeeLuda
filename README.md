#### 지금 하는 일

일본 패션 이커머스 [nugu](https://nugu.jp)의 스토어프론트와 어드민을 만듭니다.

- 레거시(Django) → BFF(MSA) 마이그레이션: API 계약을 검증하며 화면 무중단 이관
- 카페24 상품연동 등 외부 플랫폼 연동 기능 개발
- Jira 티켓만으로 관리자 웹이 수정되는 AI 코드 자동화 파이프라인 `agent-0` 설계·운영

AI가 코드를 쓰는 시대에 무엇을 만들지 판단하고, 만들어진 것을 검증하고,
사람들이 실제로 안전하게 쓰게 만드는 것이 제 일이라고 배워가고 있습니다.

주 작업은 회사 프라이빗 리포에서 이뤄집니다.

#### 주말에 하는 일

표정을 따라 하고 리액션하는 음성 AI 어시스턴트 로봇을 ESP32-S3로 만들고 있습니다.

#### 걸어온 길

판화와 타이포그라피를 공부했고, 아두이노로 미디어 아트를 만들다가
프로그래밍 세계로 빠졌습니다.

제 이력은 전공이었던 판화를 닮았습니다. 판화는 색을 직접 섞어 그림을 그리지
않습니다. 고유한 판을 하나씩 새겨 정확히 겹쳐 찍었을 때, 비로소 한 장의 그림이
나타납니다. 제 경험들도 각자의 색을 잃지 않은 채 겹쳐져, 지금의 그림이 되어갑니다.
